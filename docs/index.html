C Arrays Exercises — O(N)

This site links to exercises and explains how to submit solutions via GitHub.

  • Exercise ex01 — Sum of array

How to submit

  1. Open the repo in VSCode.
  2. Create `submissions//.c` from the `template/solution.c`.
  3. Commit and push using the VSCode Source Control UI and open a Pull Request.

See CONTRIBUTING.md for more details.
