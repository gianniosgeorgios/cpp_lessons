# Day 05 - Αφαίρεση διπλοτύπων από ταξινομημένο πίνακα

Σε ταξινομημένο πίνακα, κράτησε κάθε διαφορετική τιμή μία φορά στην αρχή του ίδιου πίνακα και επέστρεψε το νέο μήκος.

Μορφή εισόδου / εξόδου:
Έξοδος: νέο μήκος, άνω-κάτω τελεία, και τα μοναδικά στοιχεία.

Παράδειγμα:

`input.txt`
```text
8
1,1,2,2,2,3,4,4
5
1,1,1,1,1
6
-2,-2,-1,0,0,3
```

`output.txt`
```text
4:1,2,3,4
1:1
4:-2,-1,0,3
```

Απαιτήσεις:
- χρονική πολυπλοκότητα: O(N)
- χωρική πολυπλοκότητα: O(1) επιπλέον χώρος (χωρίς να υπολογίζεται η αποθήκευση της εισόδου)
