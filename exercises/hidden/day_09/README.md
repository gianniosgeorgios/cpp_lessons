# Day 09 - Two Sum με hash table

Βρες δύο διαφορετικούς δείκτες i,j ώστε a[i] + a[j] = target. Στόχος: O(N) μέσος χρόνος με hashing.

Μορφή εισόδου / εξόδου:
Η πρώτη γραμμή κάθε test case έχει N target και η δεύτερη τον πίνακα. Επέστρεψε τους δύο δείκτες.

Παράδειγμα:

`input.txt`
```text
4 9
2,7,11,15
4 6
3,2,4,9
5 10
1,8,5,2,9
```

`output.txt`
```text
0,1
1,2
0,4
```

Απαιτήσεις:
- χρονική πολυπλοκότητα: O(N) κατά μέσο όρο
- χωρική πολυπλοκότητα: O(N) για τον hash table
