# Day 08 - Στοιχείο πλειοψηφίας

Βρες το στοιχείο που εμφανίζεται περισσότερες από N/2 φορές. Θεώρησε ότι υπάρχει πάντα τέτοιο στοιχείο.

Μορφή εισόδου / εξόδου:
Χρησιμοποίησε Boyer-Moore Voting ώστε να έχεις O(1) επιπλέον χώρο.

Παράδειγμα:

`input.txt`
```text
7
2,2,1,1,1,2,2
3
3,3,4
5
-1,-1,-1,2,3
```

`output.txt`
```text
2
3
-1
```

Απαιτήσεις:
- χρονική πολυπλοκότητα: O(N)
- χωρική πολυπλοκότητα: O(1) επιπλέον χώρος (χωρίς να υπολογίζεται η αποθήκευση της εισόδου)
