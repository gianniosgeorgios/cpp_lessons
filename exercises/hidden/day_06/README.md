# Day 06 - Καλύτερη στιγμή για αγορά και πώληση μετοχής

Δίνονται τιμές μετοχής ανά ημέρα. Κάνε το πολύ μία αγορά και μία πώληση μετά την αγορά και βρες το μέγιστο κέρδος.

Μορφή εισόδου / εξόδου:
Κάθε test case έχει N και μετά τις N τιμές.

Παράδειγμα:

`input.txt`
```text
6
7,1,5,3,6,4
5
7,6,4,3,1
6
2,4,1,8,3,10
```

`output.txt`
```text
5
0
9
```

Απαιτήσεις:
- χρονική πολυπλοκότητα: O(N)
- χωρική πολυπλοκότητα: O(1) επιπλέον χώρος (χωρίς να υπολογίζεται η αποθήκευση της εισόδου)
