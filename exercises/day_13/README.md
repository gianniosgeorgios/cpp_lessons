# Day 13 - Μέγιστη διαφορά με σωστή χρονική σειρά

Δίνεται ένας πίνακας Ν ακεραίων. Να βρεις τη μέγιστη τιμή της διαφοράς `a[j] - a[i]`, με την προϋπόθεση ότι `j > i`. Αν ο πίνακας έχει λιγότερα από δύο στοιχεία ή όλες οι διαφορές είναι αρνητικές, επέστρεψε -1.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
6
7,1,5,3,6,4
```

`output.txt`
```text
5
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N)
- Επιπλέον χωρική πολυπλοκότητα: O(1)

Υπόδειξη: Μην υπολογίσεις απλώς το μέγιστο μείον το ελάχιστο: η θέση του στοιχείου είναι σημαντική.
