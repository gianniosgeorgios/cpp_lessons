# Tree 09 - Μεγαλύτερο γνήσια φθίνον μονοπάτι

**Δυσκολία:** Hard

Μονοπάτι είναι ακολουθία κόμβων όπου κάθε επόμενος κόμβος είναι παιδί του προηγούμενου. Το μονοπάτι μπορεί να ξεκινά από οποιονδήποτε κόμβο και να συνεχίζει προς τα κάτω. Επιστρέψτε το μήκος του μεγαλύτερου μονοπατιού με γνήσια φθίνουσες τιμές, μετρημένο σε ακμές. Αν δεν υπάρχει ακμή που να ικανοποιεί τη συνθήκη, επιστρέψτε 0.

Επικεφαλίδα συνάρτησης:

```cpp
int longest_decreasing_path(node *t);
```

Απαιτήσεις: O(N) χρόνος.

## Μορφή test cases
Κάθε γραμμή περιγράφει ένα δέντρο σε προδιάταξη (preorder), με κόμμα ανάμεσα στα tokens και `#` για κενό παιδί. Για παράδειγμα, `8,3,#,#,10,#,#` περιγράφει ρίζα 8 με παιδιά 3 και 10. Για ασκήσεις με παράμετρο, προστίθεται `|k` στο τέλος, π.χ. `8,3,#,#,10,#,#|2`. Κάθε γραμμή του `output.txt` είναι η αναμενόμενη απάντηση για την αντίστοιχη γραμμή εισόδου.
