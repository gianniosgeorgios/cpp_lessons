Problem: Maximum Subarray Sum (O(N))

Given an integer array of size n (n >= 1), find the contiguous subarray with the largest sum and print that sum.

Input format
- First line: integer n (1 <= n <= 100000)
- Second line: n integers separated by spaces (each fits in 32-bit signed int)

Output format
- Single integer: maximum subarray sum

Requirements
- Time complexity: O(n)

Example
Input:
9
-2 1 -3 4 -1 2 1 -5 4

Output:
6
