# Day 04 - Μετακίνηση όλων των μηδενικών στο τέλος

Μετέφερε όλα τα 0 στο τέλος του ίδιου πίνακα, κρατώντας τη σειρά των μη μηδενικών στοιχείων.

Μορφή εισόδου / εξόδου:
Η έξοδος είναι ο τροποποιημένος πίνακας.

Παράδειγμα:

`input.txt`
```text
5
0,1,0,3,12
6
1,0,2,0,0,3
4
0,0,0,1
```

`output.txt`
```text
1,3,12,0,0
1,2,3,0,0,0
1,0,0,0
```

Απαιτήσεις:
- χρονική πολυπλοκότητα: O(N)
- χωρική πολυπλοκότητα: O(1) επιπλέον χώρος (χωρίς να υπολογίζεται η αποθήκευση της εισόδου)
