# Day 09 -Δεικτης Ισορροπίας

Δίνεται ένας πίνακας. Να βρείτε τον δείκτη στον οποίο το άθροισμα των στοιχείων που βρίσκονται στα αριστερά του είναι ίσο με το άθροισμα των στοιχείων που βρίσκονται στα δεξιά του.

Αν δεν υπάρχει τέτοιος δείκτης, να επιστρέψετε -1.

Παράδειγμα:

Example:

`input.txt`
```text
6
1,7,3,6,5,6
3
1,2,3
3
2,1,-1
```

`output.txt`
```text
3
-1
0
```

Απαιτήσεις:

Χρονική πολυπλοκότητα: O(N)
