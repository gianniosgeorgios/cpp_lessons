# Day 14 - Μεγαλύτερο εμβαδόν δοχείου

Δίνεται ένας πίνακας μη αρνητικών ακεραίων. Κάθε στοιχείο αντιστοιχεί στο ύψος μιας κάθετης γραμμής. Να βρεις το μέγιστο εμβαδόν νερού που μπορεί να συγκρατηθεί ανάμεσα σε δύο γραμμές και στον οριζόντιο άξονα. Το εμβαδόν δύο γραμμών στις θέσεις i και j είναι `min(a[i], a[j]) * (j-i)`.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
9
1,8,6,2,5,4,8,3,7
```

`output.txt`
```text
49
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N)
- Επιπλέον χωρική πολυπλοκότητα: O(1)

Υπόδειξη: Χρησιμοποίησε δύο δείκτες, έναν στην αρχή και έναν στο τέλος.
