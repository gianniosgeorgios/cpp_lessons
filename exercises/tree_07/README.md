# Tree 07 - Κόμβοι με ύψος ίσο με βάθος

**Δυσκολία:** Medium

Το βάθος ενός κόμβου είναι το πλήθος ακμών από τη ρίζα μέχρι τον κόμβο. Το ύψος του είναι το πλήθος ακμών στο μεγαλύτερο μονοπάτι από τον κόμβο μέχρι φύλλο. Επιστρέψτε πόσοι κόμβοι έχουν ύψος ίσο με βάθος. Για κενό δέντρο, επιστρέψτε 0.

Επικεφαλίδα συνάρτησης:

```cpp
int count_height_equals_depth(node *t);
```

Απαιτήσεις: O(N) χρόνος· υπολογίστε τα ύψη χωρίς να επανεξετάζετε κάθε υποδέντρο πολλές φορές.

## Μορφή test cases
Κάθε γραμμή περιγράφει ένα δέντρο σε προδιάταξη (preorder), με κόμμα ανάμεσα στα tokens και `#` για κενό παιδί. Για παράδειγμα, `8,3,#,#,10,#,#` περιγράφει ρίζα 8 με παιδιά 3 και 10. Για ασκήσεις με παράμετρο, προστίθεται `|k` στο τέλος, π.χ. `8,3,#,#,10,#,#|2`. Κάθε γραμμή του `output.txt` είναι η αναμενόμενη απάντηση για την αντίστοιχη γραμμή εισόδου.
