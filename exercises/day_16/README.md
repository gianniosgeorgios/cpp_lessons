# Day 16 - Μήκος μεγαλύτερης ακολουθίας διαδοχικών τιμών

Δίνεται ένας μη ταξινομημένος πίνακας ακεραίων. Να βρεις το μήκος της μεγαλύτερης ακολουθίας διαδοχικών αριθμητικών τιμών. Οι αριθμοί της ακολουθίας δεν χρειάζεται να βρίσκονται σε συνεχόμενες θέσεις του αρχικού πίνακα. Οι διπλότυπες τιμές μετρούν μόνο μία φορά.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
6
100,4,200,1,3,2
```

`output.txt`
```text
4
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N) αναμενόμενος χρόνος
- Επιπλέον χωρική πολυπλοκότητα: O(N)

Υπόδειξη: Μπορείς να χρησιμοποιήσεις unordered_set. Ξεκίνα να επεκτείνεις ακολουθία μόνο από αριθμό που δεν έχει τον προηγούμενό του στο σύνολο.
