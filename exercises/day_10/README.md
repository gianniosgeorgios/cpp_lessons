# Day 10 - Καλύτερο κέρδος από μία αγοραπωλησία

Δίνεται ένας πίνακας `prices` με τις τιμές μιας μετοχής για Ν διαδοχικές ημέρες. Μπορείς να αγοράσεις τη μετοχή μία φορά και να την πουλήσεις μία φορά σε μεταγενέστερη ημέρα. Να υπολογίσεις το μέγιστο δυνατό κέρδος. Αν δεν είναι δυνατό να έχεις θετικό κέρδος, επέστρεψε 0.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
6
7,1,5,3,6,4
```

`output.txt`
```text
5
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N)
- Επιπλέον χωρική πολυπλοκότητα: O(1)

Υπόδειξη: Επέστρεψε 5 για τον πίνακα [7,1,5,3,6,4].
