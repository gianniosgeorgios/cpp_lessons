# Day 10 - Pivot Index

Βρες δείκτη όπου το άθροισμα αριστερά ισούται με το άθροισμα δεξιά. Αν δεν υπάρχει, επέστρεψε -1.

Μορφή εισόδου / εξόδου:
Χρησιμοποίησε συνολικό άθροισμα και τρέχον left sum.

Παράδειγμα:

`input.txt`
```text
6
1,7,3,6,5,6
3
1,2,3
3
2,1,-1
```

`output.txt`
```text
3
-1
0
```

Απαιτήσεις:
- χρονική πολυπλοκότητα: O(N)
- χωρική πολυπλοκότητα: O(1) επιπλέον χώρος (χωρίς να υπολογίζεται η αποθήκευση της εισόδου)
