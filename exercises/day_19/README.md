# Day 19 - Πλήθος αλλαγών κατεύθυνσης σε ακολουθία

Δίνεται ένας πίνακας Ν ακεραίων. Εξέτασε τις διαφορές ανάμεσα σε διαδοχικά στοιχεία και μέτρησε πόσες φορές αλλάζει η κατεύθυνση από αύξουσα σε φθίνουσα ή από φθίνουσα σε αύξουσα. Ίσες διαδοχικές τιμές αγνοούνται και δεν αλλάζουν την τελευταία μη μηδενική κατεύθυνση.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
7
1,3,5,2,2,4,1
```

`output.txt`
```text
3
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N)
- Επιπλέον χωρική πολυπλοκότητα: O(1)

Υπόδειξη: Αγνόησε τις μηδενικές διαφορές και σύγκρινε κάθε νέα μη μηδενική κατεύθυνση με την προηγούμενη.
