# Tree 08 - Μακρύτερο μονοπάτι από τη ρίζα χωρίς ίσους διαδοχικούς αριθμούς

**Δυσκολία:** Medium

Επιστρέψτε το μέγιστο πλήθος κόμβων σε μονοπάτι από τη ρίζα προς κάποιο φύλλο, στο οποίο δύο διαδοχικοί κόμβοι δεν έχουν ίδιες τιμές. Αν δεν υπάρχει τέτοιο μονοπάτι, επιστρέψτε 0. Ένα μονοπάτι που περιέχει μόνο τη ρίζα είναι έγκυρο όταν το δέντρο έχει έναν κόμβο.

Επικεφαλίδα συνάρτησης:

```cpp
int longest_path_no_equal_adjacent(node *t);
```

Απαιτήσεις: O(N) χρόνος.

## Μορφή test cases
Κάθε γραμμή περιγράφει ένα δέντρο σε προδιάταξη (preorder), με κόμμα ανάμεσα στα tokens και `#` για κενό παιδί. Για παράδειγμα, `8,3,#,#,10,#,#` περιγράφει ρίζα 8 με παιδιά 3 και 10. Για ασκήσεις με παράμετρο, προστίθεται `|k` στο τέλος, π.χ. `8,3,#,#,10,#,#|2`. Κάθε γραμμή του `output.txt` είναι η αναμενόμενη απάντηση για την αντίστοιχη γραμμή εισόδου.
