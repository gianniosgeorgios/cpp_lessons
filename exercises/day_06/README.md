# Day 06 - Second largest element

Find the second largest element in the array.

The array contains distinct integers and the second largest value always exists.

Example:

`input.txt`
```text
5
4,9,2,11,7
6
12,5,8,10,3,7
5
-5,-10,-2,-20,-7
```

`output.txt`
```text
9
10
-5
```

Requirements:
- time complexity: O(N)
- extra space complexity: O(1)
