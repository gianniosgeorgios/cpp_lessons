# Day 17 - Μέγιστο άθροισμα γινομένων συνεχόμενων στοιχείων

Δίνεται ένας πίνακας Ν μη μηδενικών ή μηδενικών ακεραίων. Να βρεις το μέγιστο γινόμενο που προκύπτει από οποιονδήποτε μη κενό συνεχόμενο υποπίνακα.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
4
2,3,-2,4
```

`output.txt`
```text
6
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N)
- Επιπλέον χωρική πολυπλοκότητα: O(1)

Υπόδειξη: Παρακολούθησε τόσο το μέγιστο όσο και το ελάχιστο γινόμενο που τελειώνει στην τρέχουσα θέση, επειδή ένας αρνητικός αριθμός μπορεί να αλλάξει πρόσημο.
