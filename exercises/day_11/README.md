# Day 11 - Μέγιστο άθροισμα συνεχόμενου υποπίνακα

Δίνεται ένας πίνακας Ν ακεραίων. Να βρεις το μέγιστο άθροισμα που μπορεί να έχει ένας μη κενός συνεχόμενος υποπίνακας.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
9
-2,1,-3,4,-1,2,1,-5,4
```

`output.txt`
```text
6
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N)
- Επιπλέον χωρική πολυπλοκότητα: O(1)

Υπόδειξη: Πρέπει να επιλέξεις τουλάχιστον ένα στοιχείο. Ο πίνακας μπορεί να περιέχει μόνο αρνητικούς αριθμούς.
