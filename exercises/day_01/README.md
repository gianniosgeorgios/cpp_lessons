# Day 01 - Μέγιστο στοιχείο σε έναν πίνακα

Δίνεται ένας πίνακας που περιέχει Ν ακέραιους αριθμούς.
Να βρεθεί και να εκτυπωθεί η μέγιστη τιμή του πίνακα.

Η πρώτη γραμμή της εισόδου περιέχει έναν ακέραιο Ν, το πλήθος των στοιχείων του πίνακα.

Η δεύτερη γραμμή περιέχει Ν ακέραιους αριθμούς, τα στοιχεία του πίνακα.

Κάθε test case δίνεται ανεξάρτητα.
Παράδειγμα:

`input.txt`
```text
8
3 8 1 9 4 12 5 7
6
5 -4 -9 -3 -1 -7
```

`output.txt`
```text
12
-1
```

Απαιτήσεις:
- χρονική πολυπλοκότητα: O(N)
- χωρική πολυπλοκότητα: O(1) επιπλέον χώρος (χωρίς να υπολογίζεται η αποθήκευση της εισόδου)
