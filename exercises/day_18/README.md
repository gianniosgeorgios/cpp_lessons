# Day 18 - Πλήθος στοιχείων μεγαλύτερων από όλα τα προηγούμενα

Δίνεται ένας πίνακας Ν ακεραίων. Να μετρήσεις πόσα στοιχεία είναι αυστηρά μεγαλύτερα από όλα τα στοιχεία που βρίσκονται πριν από αυτά. Το πρώτο στοιχείο μετρά πάντα, επειδή δεν έχει προηγούμενα στοιχεία.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
7
3,1,4,4,6,2,7
```

`output.txt`
```text
4
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N)
- Επιπλέον χωρική πολυπλοκότητα: O(1)

Υπόδειξη: Κράτησε το μεγαλύτερο στοιχείο που έχεις δει μέχρι τώρα. Η σύγκριση είναι αυστηρή.
