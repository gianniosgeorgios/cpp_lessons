# Tree 10 - Διάμετρος δυαδικού δέντρου

**Δυσκολία:** Hard

Η διάμετρος είναι το μέγιστο πλήθος ακμών σε οποιοδήποτε μονοπάτι ανάμεσα σε δύο κόμβους του δέντρου. Το μονοπάτι δεν χρειάζεται να περνά από τη ρίζα. Για κενό δέντρο ή δέντρο με έναν κόμβο, επιστρέψτε 0.

Επικεφαλίδα συνάρτησης:

```cpp
int tree_diameter(node *t);
```

Απαιτήσεις: O(N) χρόνος: σε κάθε κόμβο υπολογίστε μαζί το ύψος και την καλύτερη διάμετρο.

## Μορφή test cases
Κάθε γραμμή περιγράφει ένα δέντρο σε προδιάταξη (preorder), με κόμμα ανάμεσα στα tokens και `#` για κενό παιδί. Για παράδειγμα, `8,3,#,#,10,#,#` περιγράφει ρίζα 8 με παιδιά 3 και 10. Για ασκήσεις με παράμετρο, προστίθεται `|k` στο τέλος, π.χ. `8,3,#,#,10,#,#|2`. Κάθε γραμμή του `output.txt` είναι η αναμενόμενη απάντηση για την αντίστοιχη γραμμή εισόδου.
