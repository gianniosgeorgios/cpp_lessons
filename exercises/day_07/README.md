# Day 07 - Μέγιστο άθροισμα συνεχόμενου υποπίνακα

Βρες το μέγιστο άθροισμα οποιουδήποτε συνεχόμενου υποπίνακα (Kadane).

Μορφή εισόδου / εξόδου:
Κάθε test case έχει N και μετά τον πίνακα.

Παράδειγμα:

`input.txt`
```text
9
-2,1,-3,4,-1,2,1,-5,4
4
-5,-2,-8,-1
5
1,2,3,4,5
```

`output.txt`
```text
6
-1
15
```

Απαιτήσεις:
- χρονική πολυπλοκότητα: O(N)
- χωρική πολυπλοκότητα: O(1) επιπλέον χώρος (χωρίς να υπολογίζεται η αποθήκευση της εισόδου)
