# Day 07 - Έλεγχος ταξινομημένου πίνακα

Δίνεται ένας πίνακας ακεραίων. Να διαπιστωθεί αν ο πίνακας είναι ταξινομημένος σε μη φθίνουσα σειρά (ascending order), δηλαδή κάθε στοιχείο είναι <= το επόμενο. Τα διπλότυπα επιτρέπονται.

Σε περίπτωση που είναι ταξινομημένος να επιστρέφει 1, αλλιώς 0.

Παράδειγμα:

`input.txt`
```text
5
2,4,7,9,11
5
2,4,1,9,11
6
-3,-3,-1,2,5,8
```

`output.txt`
```text
1
0
1
```

Απαιτήσεις:
- time complexity: O(N)
