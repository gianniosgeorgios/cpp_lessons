# Day 15 - Παγιδευμένο νερό μετά τη βροχή

Δίνεται ένας πίνακας μη αρνητικών ακεραίων που περιγράφει το ύψος κάθε μπάρας σε ένα τοπίο. Να υπολογίσεις πόσες μονάδες νερού μπορούν να παγιδευτούν μετά τη βροχή.

Η πρώτη γραμμή κάθε test case περιέχει το πλήθος Ν των στοιχείων. Η δεύτερη γραμμή περιέχει τα Ν στοιχεία, χωρισμένα με κόμμα.

Παράδειγμα:

`input.txt`
```text
12
0,1,0,2,1,0,1,3,2,1,2,1
```

`output.txt`
```text
6
```

Απαιτήσεις:
- Χρονική πολυπλοκότητα: O(N)
- Επιπλέον χωρική πολυπλοκότητα: O(1)

Υπόδειξη: Το νερό σε κάθε θέση περιορίζεται από το ψηλότερο εμπόδιο αριστερά και δεξιά.
